# 按实际加载的规则领域提供模块画像事实

Status: accepted（2026-11-24）

主工程加载模块规则时，画像事实取自该模块已采纳的规则快照。对核心领域、显式选中的领域，以及沿必读依赖实际加载规则正文的领域，均提供该领域已批准导出的全部事实。这样可以复用现有的领域标注，并让主工程读到模块已共享的依据，代价是有时会多读同一领域的几条事实。

例如，模块的后端规则必须同时读取数据库迁移规则。若快照已采纳八条数据库域事实，本次加载应带上全部八条。后端索引中的普通导航链接只作查找提示。涉及多个模块时，各自使用本模块快照的导出范围。[模块导出与加载约定](../../skills/ai-rulers-init/references/module-workflows.md)
